What is XDAO?

XDAO is a multi-chain DAO framework for creating blockchain organizations, managing shared crypto assets, and approving treasury actions through voting. Its official documentation covers setup, governance tokens, supported blockchains, and security resources.

How XDAO works

  1. Open the official appUse the verified app domain, choose the desktop EVM route or Telegram route, and connect the wallet you intend to use.
  2. Create or select a DAOStart a new organization or open an existing workspace before setting treasury and member controls.
  3. Set governance rulesConfigure members, voting power, quorum, and proposal rules so treasury actions require approval.
  4. Review before signingCheck the network, wallet prompt, and transaction details before deploying or approving any on-chain action.

Before you explore

Teams can coordinate member roles, voting thresholds, proposals, and treasury actions through a shared organization wallet.

XDAO FAQ

What is xdao?

xdao is a Web3 tool for creating and managing DAOs, including treasury workflows, member coordination, governance voting, and shared asset management.

Is xdao the official app?

This page is a gateway, not the product itself; the official action URL is app.xdao.app/1.

What can I do with xdao?

You can create a DAO, configure governance settings, manage a treasury, coordinate members, and use supported modules such as crowdfunding or DeFi interactions where available.

Which networks does xdao support?

The official site lists broad EVM-compatible network support plus TON access for Telegram workflows; check the app and docs for the current live network list.

What does xdao mean by DAO governance?

DAO governance means shared rules for proposals, voting, and execution; Ethereum.org provides a neutral DAO overview for the broader concept.
